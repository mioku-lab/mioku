## 项目定位

Mioku 是一个插件式机器人框架，围绕 Agent 能力构建。框架自身提供事件、Bot 连接、插件加载与服务管理。AI 能力、截图和配置以服务的形式按需装配，插件可以自由组合这些能力。

Mioku 的命名取自初音未来主题，名字中包含 Miku，同时代表开源。
