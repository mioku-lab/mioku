# 认识 Mioku

Mioku 是一个插件式机器人框架，使用 TypeScript 编写，运行在 Node.js 22.18 及以上版本。它做两件事。第一件是把平台消息转换成插件可以处理的事件。第二件是把插件要执行的动作转换成平台指令。机器人具体做什么由插件决定，例如聊天、查天气、管理群、看图说话。

## 机器人的构成

一个 Mioku 机器人由四部分组成。

1. **适配器 Adapter**：负责对接具体平台。它把平台的原始消息转换成统一事件，也把插件要执行的操作翻译成平台指令。
2. **能力 Capability**：适配器对外承诺的操作。发送消息、禁言成员、查询群列表各是一项能力，由适配器注册，插件按需调用。
3. **插件 Plugin**：机器人的功能本体。插件声明自己的名字，然后监听事件、调用能力、完成任务。
4. **服务 Service**：跨插件复用的能力提供方，例如 AI 服务、配置服务和截图服务。插件按服务名取用。

四者的关系如下。

```text
          平台 QQ / OneBot / 终端
                    ↓
          适配器 Adapter
          mioku-adapter-onebotv11 / icqq / stdin
                    ↓
          能力 Capability
          由适配器注册可执行的操作
                    ↓
          事件总线 EventBus
                    ↓
     ┌──────────────┴──────────────┐
  插件 Plugin                  服务 Service
  功能实现                      能力提供
```

适配器负责连接，能力负责操作。插件不需要知道对面是 NapCat 还是 icqq，它只看到一组能力。这些能力由谁实现，插件不需要知道。

## Agent 优先

Mioku 的核心设计取向是 Agent 优先。机器人不只在收到关键词时回复，还会让 AI 理解消息、调用工具、完成任务。框架内置了完整的 AI 服务契约，包含实例、提供商、模型、技能和用量统计。插件注册一个技能后，AI 就能在对话中调用它。`chat` 插件是这套体系的主要使用者。
