# mioku-plugin-chat

Mioku AI 智能聊天插件。

## 功能

- AI 对话
- 群聊 / 私聊支持
- 技能系统
- 群聊长期记忆 + 资料查找
- 人格化引擎
- 伪人模式

## 依赖服务

- ai: AI 实例管理
- config: 配置管理
- help: 帮助服务
- screenshot: 网页截图
- vector: 本地向量检索

## 命令

| 命令 | 权限 | 说明 |
|---|---|---|
| `.记忆` | 所有人 | 查看记忆状态（条数、待抽取、缓存、上次抽取、最近错误） |
| `.记忆 搜索 <关键词>` | 所有人 | 只搜本群的记忆条目（不混入画像、话题、原文） |
| `.记忆 轮廓 <群员>` | 所有人 | 查看某个群员的画像与相关记忆 |
| `.记忆 抽取` | 管理员 | 立刻抽取当前群（验证流水线用） |
| `.记忆 忘掉 <id>` | 管理员 | 删除一条记忆 |
| `.记忆 清空` | 管理员 | 清空本群记忆、画像与索引 |
| `.记忆 重建` | 管理员 | 换向量模型后重建索引 |


## 安装

```bash
bun add mioku-plugin-chat
```
